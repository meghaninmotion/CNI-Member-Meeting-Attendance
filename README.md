# CNI-Member-Meeting-Attendance
A prototype timeline mapping of CNI member attendance at spring and fall member meetings

This timeline and bubble map presents the volume of attendees and the percentage of member organizations at spring and fall CNI meetings from 2018-2026. More details on the organizations can be found at https://www.cni.org/about-cni/membership/members.

This map was developed by pairing with Claude AI to develop html to represent the size and distribution per CNI meeting, and is presented for exploration. It can be further developed with your feedback and suggestions. Please share those thoughts - and report errors - as pull requests!
